## ⚠ Importante

Los datos de FinanceOS se guardan en el navegador del dispositivo.
**Sin backup previo, los datos no se pueden recuperar —
ni por el usuario ni por MAXNOVA & LUCI Global LLC.**

---

## Crear un backup

1. Abrí FinanceOS → Ajustes
2. Sección "Respaldo y restauración"
3. Clic en "↓ Crear respaldo"
4. Se descarga un archivo JSON
5. Guardalo en Google Drive, iCloud, email u otro lugar seguro

---

## Restaurar un backup

1. Abrí FinanceOS → Ajustes
2. Clic en "↑ Restaurar"
3. Seleccioná el archivo JSON de backup
4. Confirmá el reemplazo
5. Los datos se restauran inmediatamente

---

## Frecuencia recomendada

- **Uso personal:** 1 vez por mes mínimo
- **Con clientes (Pro):** al finalizar cada sesión
- **Antes de cambiar de dispositivo o navegador**

---

## Para asesores (plan Pro)

Instruí a cada cliente para crear un backup mensual.
Cada cliente tiene su propia instancia independiente.
Vos no tenés acceso a los datos de tus clientes.
